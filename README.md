# tw-foodstand-labels

Optional trailer label textures for **Tworst Food Stands** (`tw-foodstandjob`). Free download.

The printed texts on the trailers (ingredient tags on the counters, the ice cream sign, the burger, pizza and sushi
boards) follow the job language (`Config.Locale`). English and Chinese are in the job package. The other 12 languages
are here, so players do not download textures your server never uses.

## Install

1. Download **`tw-foodstand-labels.zip` from [Releases](https://github.com/Tworst-Shop/tw-foodstand-labels/releases/latest)**.
2. Copy only the file for your language (`tw_label_<code>.ytd`) into `tw-foodstandjob/stream/label_lang/`.
   Or extract the whole zip into `resources/[tw-foodstand]/`: the folders match.
3. Restart the server, so every player downloads the new file.

Copy only the language you use. Each file is about 1.6 MB, and every player downloads every file in `stream/`.

If the file for your language is missing, the trailers stay in English. Nothing breaks.

## Compatibility

Works with `tw-foodstandjob` 1.0.0 and newer. When a job update changes the labels, a new release appears here.
